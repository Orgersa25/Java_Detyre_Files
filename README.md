# Detyrë Praktike në Java – File Stream

Ky projekt lexon një skedar me emrin `input.txt`, konverton çdo rresht në shkronja të mëdha dhe i ruan rezultatet në `output.txt`.

## Karakteristikat

- Lexim nga `input.txt`
- Konvertim në uppercase
- Shkrim në `output.txt`
- Mesazh suksesi pas përfundimit
- (Opsionale) Krijon `input.txt` bosh nëse nuk ekziston

## Ekzekutimi

1. Sigurohuni që `input.txt` ndodhet në të njëjtën direktori.
2. Ekzekutoni programin:
   ```bash
   javac FileConverter.java
   java FileConverter
